🔗Verbindungen
Belabox-Encoder und alle angebundenen Router/Hotspots.
Belabox-Encoder
Nach Einrichtung des VPN's per Skript ("Fernzugriff einrichten" auf dem Desktop) erhält die Belabox immer eine feste IP im VPN-Netz. SSH-Nutzer und Passwort entnehmen Sie der BelaboxUI und das belaUI-Passwort ist das, welches Sie zum Login auf die Belabox in der WebGUI verwenden.
Was bedeutet das?

Muss exakt dem Namen der Quelle in OBS entsprechen, die den Belabox/SRT-Stream anzeigt (Standard: "Belabox Stream" - so heisst die Quelle in den mitgelieferten LIVE/LOW-Szenen bereits automatisch). Bei einem Netzwerk-Ausfall (siehe "SRTLA-Ausfall"-Meldungen) wird genau diese Quelle automatisch neu geladen, um den bekannten "Kassette verlangsamt"-Audioeffekt zu beheben - falscher Name = der Fix greift ins Leere.
